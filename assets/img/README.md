# Profile photo

Put your photo here as **`profile.jpg`** and it appears next to the intro text.

- **Square crop** — the page renders it at 132 × 132 CSS pixels, so ~400–600 px on a
  side is plenty (and keeps the repo small). Anything non-square gets center-cropped.
- **jpg or png.** For a different filename or format, change `PROFILE.photo` in
  `assets/js/data.js` (e.g. `"assets/img/me.png"`).
- **No photo?** Set `PROFILE.photo: ""` and the photo block disappears entirely.

Until a file is here, the page shows a grey placeholder with the expected path
written on it, so it is obvious what is missing.
